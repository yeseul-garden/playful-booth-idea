# 디자인 적용 및 검증 기록

## 이번 수정 범위

Playful Booth는 현장 전광판과 운영자 설정을 위한 앱 화면이다. 두 뷰, 응답 연결, 기존 버튼과 경로를 유지하면서 초기 행사 설정을 추가했다. `hanmadi` 소스는 수정하지 않았다.

원본 스크린샷에서 카드형 메모는 `height:100%`로 그리드 칸 전체를 채워 과하게 길어졌고, 우주형은 이미 줄인 본문으로 다음 표시 줄 수를 다시 계산해 짧은 응답까지 생략했다. 고정 헤더 높이와 실제 제목 높이가 달라질 여지도 있었다.

- 카드 폭을 먼저 확보하고 남은 세로 공간으로 행 수를 결정한다.
- 본문 높이 예산은 카드가 사용할 수 있는 칸 높이에서 패딩·간격·작성자 영역을 뺀 값이다. 이미 잘린 본문 높이를 기준으로 재계산하지 않는다.
- 카드 높이는 본문에 맞춘다. 아주 긴 응답만 최소 글자 크기를 유지하며 줄이고 전체 보기를 제공한다.
- 글꼴 로딩·제목 높이·화면 크기 변경 후 배치를 재계산한다.

## 적용한 디자인 원칙

### Taste Skill

출처: https://github.com/Leonxlnx/taste-skill (MIT).

같은 좌우 기준선, 실제 사용자 콘텐츠가 중심인 화면, 일관된 버튼·글꼴·카드 체계와 화면 크기별 확인 원칙을 적용했다. 회사 소개용 랜딩 페이지 템플릿·사진·섹션 배치·무작위 팔레트는 전광판 앱과 지정 팔레트에 맞지 않아 사용하지 않았다. 전용 Taste 빌드·게이트 전체를 실행한 결과로 주장하지 않는다.

### Unslop

출처: https://github.com/heydamir/unslop, Damir Sokolovsky, CC BY 4.0.

관련 지침을 이 프로젝트에 맞게 수정·적용했다. 반복 영문 대문자 장식, 넓은 자간, 감탄형 장식 카피를 줄이고 운영 UI는 낮은 채도, 카드 콘텐츠는 지정 색상으로 분리했다. 간격·색·아이콘·문구·타이포·배치·디테일·모션 순서로 검토했다. 기본 별은 사용자 요청을 따라 유지하되 글꼴 문자 대신 같은 형태의 선형 SVG로 안정적으로 표시한다.

### Hallmark

출처: https://github.com/Nutlope/hallmark (MIT).

기존 앱과 실제 기능을 보존하며 색·글꼴 토큰, focus-visible, 모션 줄이기, 입력 테두리 대비, 이미지 그리드의 최소 폭, disabled 상태를 정리했다. 운영자에게 필요한 설정 화면과 실제 응답 표시를 중심으로 구성했다. 별도 테마나 홍보 페이지로 바꾸지 않았다.

공식 `sloplint.mjs`를 `--scope app --genre playful --render`로 실행했다. 대상은 `public/index.html`, `public/styles.css`와 로컬 시작 화면이다. 최종 자동 결과는 **FAIL 0 / REFLEX 0 / WARN 4**다. 전체 원격 시트 연결이나 두 뷰의 데이터 상태까지 이 결과가 보증하지는 않는다.

남긴 경고 4개:

- 헤더 반투명·블러: 기존 반투명 헤더 요구를 유지했다. 실제 카드에는 유리 효과를 쓰지 않는다.
- 신규 응답 스포트라이트의 배경 블러: 새 응답에 시선을 모으는 일시적 연출이다. 사용자가 요청한 새 응답 강조 기능에만 사용한다.
- 두 개의 채운 버튼으로 판단: 기본 별 복원은 투명 배경의 텍스트 버튼이고, 주 동작만 노란 배경이다. 시작 화면의 실제 계산 스타일을 확인한 뒤 오탐으로 기록했다.
- 다이얼로그의 얇은 테두리와 그림자: 헤더나 카드가 아닌 일시적인 연결 설정 대화상자의 경계와 구분을 위해 유지했다.

스크립트가 특정 디자인 관용구를 경고한 것이며, 승인·인증·브라우저 접근 제한을 우회한 결과가 아니다. 별도 모델 리뷰나 전체 Taste 게이트 완료로 표시하지 않는다.

## 검증 범위

- 단위 테스트 16개 통과.
- 별도의 headless Chrome 테스트 프로필에서 1920×1080, 768×1024, 627×865, 390×844, 3840×2160을 두 뷰씩 총 10화면 검사했다.
- 기본 샘플 답변에서 불필요한 말줄임 0건. 좌우 화면 이탈, 카드와 헤더·푸터 충돌, 본문과 작성자 논리 영역 겹침이 없음을 검사했다. 회전한 카드의 축 기준 외접 사각형은 서로 겹칠 수 있으므로 본문과 작성자의 내부 좌표로 검증한다.
- 최초 이름 입력, 공백 제목 거부, 아이콘 업로드·기본 별 복원, 설정 복귀, 긴 제목 헤더 높이 조정, 답변 상세보기, 신규 도착 효과, 저장한 제목 재로드를 확인했다. 추가로 수천 자의 긴 응답과 HTML 형태의 문자열이 전체보기에서 원문 그대로 표시되고, 코드로 실행되지 않으며, 모션 줄이기 설정에서 애니메이션이 꺼지는지 확인했다.
- Google 계정에서 실제 Apps Script 배포·권한 승인·폼 제출을 포함한 테스트는 하지 않았다. 기존 연결 코드와 시트는 변경하지 않았다.

검사 도구와 스크린샷은 실행 시점의 개발 증거이며 반응형·접근성의 전면적인 인증을 의미하지 않는다.

## Booth buddy 랜딩 재구성

제공한 디자인 시스템을 우선하는 브랜드 리디자인이다. 원본 B안 로고와 폰트를 복사하고 `brand/tokens.css`를 수정 없이 사용했다. 기존 설정 폼 첫 화면을 제품 랜딩, 독립 행사 설정, 전광판의 세 화면으로 분리했다. 랜딩은 브랜드 내비게이션, 실제 용도에 맞춘 카드형 예시, 보드 만들기와 샘플 탐색, 사용 절차로 구성했다. 구글폼 연결과 두 뷰는 기존 상태 로직을 유지한다. 컬러 로고를 다시 그리지 않았으며 블루 배경에는 단색 심벌을 사용한다. 앞 절의 Hallmark 수치는 이전 리비전의 기록이며 이번 랜딩 전체의 검사 통과 주장으로 사용하지 않는다.
